# Scenario: Create New Spec and Add Timer Component

## Description
This scenario validates the end-to-end user workflow of creating a brand-new specification from the AI Assistant UI and generating a hardware component using natural language interaction. The proposal generated by the AI Assistant is reviewed and approved, and the resulting component is verified across both the AI Assistant UI and the Spec Editor UI.

## Preconditions
- The Spec Editor service is running at `http://127.0.0.1:6010`.
- The AI Assistant service is running at `http://127.0.0.1:6013`.
- An active `OPENAI_API_KEY` is configured in the environment.

## Test Parameters
- **Target Domain**: `spec`
- **Spec Document ID**: `ui_timer_spec`
- **Spec Title**: `UI Automation Timer Spec`
- **Preset**: `focused`
- **Component Name**: `timer_core`
- **User Prompt**: `Create a timer component named timer_core with 32-bit counter, clk and rst_n inputs, and irq output.`

## Execution Steps

### Step 1: Open AI Assistant
- Navigate browser to `http://127.0.0.1:6013`.
- Confirm the DeepSeek Harness / AI Assistant interface loads properly.

### Step 2: Create a New Spec Session
- Click the **New conversation** or target chooser button to open the design source dialog.
- Select the **Create new** radio option.
- Enter **Document ID**: `ui_timer_spec`.
- Enter **Title**: `UI Automation Timer Spec`.
- Select Preset: `focused`.
- Click **Create & open** to establish the bound conversation session.

### Step 3: Send Natural Language Prompt
- Focus the chat input box.
- Input the prompt: `Create a timer component named timer_core with 32-bit counter, clk and rst_n inputs, and irq output.`
- Submit the message turn.

### Step 4: Review and Approve Component Proposal
- Wait for the AI Assistant turn to complete.
- Verify that a proposal card or details card appears for `timer_core`.
- If a details card appears with "Continue proposal", click it to confirm.
- Verify the proposal review card renders the proposed IP-XACT component and SystemVerilog ports (`clk`, `rst_n`, `irq`).
- Click the **Approve** button on the proposal review card to commit the changes to the specification.

### Step 5: Verify Results in AI Assistant UI
- Ensure the proposal state indicator changes to approved / applied.
- Ensure no error notification or failure banner appears in the session.

### Step 6: Verify Results in Spec Editor UI
- Navigate the browser to the Spec Editor at `http://127.0.0.1:6010/specs/ui_timer_spec` (or open the document from the Spec Editor index).
- Verify that `ui_timer_spec` loads successfully.
- Verify that `timer_core` appears in the components tree / table.
- Verify that the ports (`clk`, `rst_n`, `irq`) are listed under the component.

# Document import fixtures

These small, authored fixtures contain the same title, reset statement, and port
table. DOCX and ODT also contain a simple embedded diagram. Archive timestamps
are fixed. No designer data, model output, or external document is included.

Use these files with the real import CLI. Do not replace the document reader
with a fixture response. PDF parsing can also require cached Docling model
assets. Missing import dependencies leave these checks unverified.

## 6. Confirmed Defects and Added Protections

1. **`CreateHardware` VLNV parameter omission**:
   - *Defect*: Calling `create_entity` without a custom `vlnv` defaulted unconditionally to `spec2gds.local:work:<name>:1.0`, preventing authoring with canonical `spec2gds.local:<category>:<id>:1.0.0`.
   - *Fix*: Added optional `vlnv` field to `CreateHardware` transaction dataclass, JSON schema, and decoder, with validation via `validate_vlnv`. Added regression test `tests/spec/spec_format/test_creation_vlnv.py`.

2. **Verilator 64-bit Modulo Constant Subtraction Width Warning**:
   - *Defect*: `counter_modulo` preset `p3` (`W=64`) produced `%Warning-WIDTHEXPAND` in Verilator when subtracting 1 from 32-bit `MODULUS`.
   - *Fix*: Replaced `W'(MODULUS - 1)` with `W'(MODULUS) - 1'b1` in RTL.

3. **Verilator Testbench Clock Blocking Assignment**:
   - *Defect*: `clk_i = ~clk_i` in testbench triggered `%Warning-BLKSEQ`.
   - *Fix*: Replaced with non-blocking assignment `clk_i <= ~clk_i;` and added `-Wno-BLKSEQ` compiler flag.

4. **React Package Resolution in AI Assistant Harness Integration Tests**:
   - *Defect*: `tests/spec-flows.integration.test.mjs` failed resolving `react/package.json` from `ai-assistant/package.json` due to uninstalled peer modules in `ai-assistant/node_modules`.
   - *Fix*: Synced locked React 18.3.1 modules from `circuit-designer` into `ai-assistant/node_modules/`, resolving all 23 harness test cases.

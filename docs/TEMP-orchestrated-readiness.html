What the available checks establish

The Assistant server build passed. Fourteen focused policy/configuration/instruction tests and two native Goal/Orchestrated integration tests passed. Integration used a fixture model and local HTTP service; it did not measure live-model quality or functional RTL correctness. The full report records required profile results, HTML checks, and evidence limits.

What needs new design decisions

Define each monitor's durable reaction intent and completion criterion. Consider typed review verdicts when automated decisions must be enforced. Measure obsolete results, event bursts, and self-triggered source edits. The existing caps bound growth but do not create an indefinitely funded service.

Why Activities remain deterministic

An Activity consumes an immutable Spec snapshot through its SDK. Queue/process/HTTP hosting is a separate boundary. The model must not infer hardware behavior from narrative. Activity adapters need explicit job identity, result/provenance, failure, cancellation, and service approval rules.

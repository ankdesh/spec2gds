Install a release. Keep Harness development separate.

spec2hw can use DeepSeek Harness without cloning its source repository. It downloads the built packages that its selected profile requires.

Package
A named archive of reusable code and its required files.
Registry
A service that stores package versions and checks who can download them. GitHub runs this service for us.
Dependency
A package your application needs. That package can need other packages too. These are indirect dependencies.
Version lock
A file that records exact package versions and checksums. It helps each machine install the same code.

  1. Build once

    Harness developers change source code. Automated checks build and test a selected package set.

  2. Publish to GitHub

    The release process uploads the tested archives to npm.pkg.github.com under @ankdesh.

  3. Install in spec2hw

    The repository includes the selected release archives. The lock file installs them locally. The application builds only its own code.

Do I need a registry account or token?

No. The repository includes 175 original Harness archives under ai-assistant/vendor/harness/, totalling 6.36 MB. Setup verifies their checksums before npm extracts and installs them. Licence files remain inside the archives.

scripts/setup-all.sh

For Assistant dependencies alone, run npm --prefix ai-assistant run install:packages. Public npm dependencies still download from their usual registry. A GitHub package token is needed only by a release maintainer who downloads a new private release.

Does everything have to use npm?

No. npm is the package format used for the Harness Node.js modules. Both npm and pnpm can install that format. Python code keeps its Python tools. KLayout and system tools keep their own installation methods.

A container image can include these parts later. A container is a larger deployment unit; it does not remove the need to select and lock its contents.

Private packages need read access. A developer uses a GitHub token. A permitted GitHub Actions job can use its job token. GitHub-hosted npm packages require authentication even after their visibility becomes public.

ONE EXAMPLE · EXPLICIT BEHAVIOR

Registered 16-bit adder

A combinational adder feeds one enabled register. Every interface and connection is explicit.

16-bit modulo adder

Produce y = (a + b) modulo 65536. This Component is combinational. It has no clock, reset, or carry output. The Ports and SystemVerilog sections define the interface and behavior.

Port IDDirectionRangeDescription
ain15:0First unsigned operand.
bin15:0Second unsigned operand.
yout15:0Unsigned sum, modulo 65536.
assign y = a + b;

Enabled 16-bit register

On each rising clk edge, reset=1 clears dout to zero. Otherwise enable=1 captures din. Otherwise dout holds its value. Reset is synchronous and active high. Reset has priority over enable. There is no ready/valid handshake.

Port IDDirectionRangeDescription
clkinLeave blank (scalar)Rising-edge clock.
resetinLeave blank (scalar)Synchronous active-high reset; highest priority.
enableinLeave blank (scalar)Capture din when reset is zero.
dinin15:0Unsigned data to capture.
doutout15:0Registered output.
always_ff @(posedge clk) begin
    if (reset) dout <= '0;
    else if (enable) dout <= din;
end

Registered 16-bit adder

R1: On a rising clk edge with reset=1, y becomes zero, regardless of enable. R2: Otherwise, when enable=1, y captures (a+b) modulo 65536. R3: Otherwise y holds its value. Reset is synchronous and active high. The internal Design contains u_add and u_reg. There is one register stage. No valid signal or carry output is present.

The containing Component has no SystemVerilog section. Its internal Design instantiates u_add and u_reg.

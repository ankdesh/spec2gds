Compose a Design from Components

Create a containing Design with two reusable Component instances.

Before you startActionsCheck your resultTry itIf it fails

Before you start

Spec Editor. The prepared start supplies the adder, register, and containing Component interface. It has no internal Design yet.

START HERE

temp/TEMP_tutorials/my-run/05-start.spec

Prepare or reset a lesson →

This lesson adds a supplied containing interface to the earlier results. Continue from your own Spec with the listed setup, or use this prepared checkpoint.

Read each action, do it, then compare the expected result before continuing. Use a fresh prepared start to retry. Reading time and automated execution time are not measured learner practice time.

Actions

  1. Inspect the prepared interface

    Open 05-start.spec. It supplies both leaf Components and the containing Registered 16-bit adder interface. If continuing your own Spec, create that containing Component first using this table and explanation.
    Port IDDirectionRangeDescription
    ain15:0First unsigned operand.
    bin15:0Second unsigned operand.
    clkinLeave blank (scalar)Rising-edge clock.
    resetinLeave blank (scalar)Synchronous active-high reset.
    enableinLeave blank (scalar)Capture the addition result.
    yout15:0Registered sum, modulo 65536.
    R1: On a rising clk edge with reset=1, y becomes zero, regardless of enable. R2: Otherwise, when enable=1, y captures (a+b) modulo 65536. R3: Otherwise y holds its value. Reset is synchronous and active high. The internal Design contains u_add and u_reg. There is one register stage. No valid signal or carry output is present.

    Expected result: The containing Component has six boundary ports and no SystemVerilog body or Internal Design.

  2. Start internal Design creation

    On the containing Component select Options → Create internal Design…. Enter Registered adder implementation.

    Expected result: The creation dialog is open. The saved Spec has not changed.

  3. Review the interface

    Read the dialog. The internal Design uses the containing Component’s ports and parameters.

    Expected result: No separate top-level Design or duplicated interface is needed.

  4. Create and assign the implementation

    Select Create internal Design. Creation and assignment save together.

    Expected result: The internal Design appears under its Component. It has no instances or connections and is not an entry Design. Any retained SV is reference text.

  5. Add the adder instance

    On the Design select Options → Add component instance…. Set Instance ID to u_add and choose the existing 16-bit modulo adder. Select Add instance.

    Expected result: One instance refers to the existing adder definition.

  6. Add the register instance

    Repeat for Instance ID u_reg, using Enabled 16-bit register.

    Expected result: Exactly two instances reuse the existing leaf definitions.

  7. Read the instance table

    Compare both instance IDs and Component references. Inspect the Design circuit preview.

    Expected result: The preview has two blocks and the containing boundary, without signal connections.

  8. Open the Design projection

    Use the Design’s Options → Open in Circuit Designer. Inspect the binding notice.

    Expected result: An editable source-bound Circuit opens. A leaf Component preview would be read-only.

  9. Confirm the saved setup

    Return to Spec Editor and reopen the same Spec.

    Expected result: The Internal Design assignment and both instances persist. The next exercise starts from this unconnected topology.

SAVED-STATE CHECK

Check your result

The containing Component has six boundary ports and one internal Design. That Design has exactly u_add and u_reg, with no connections yet.

Try it yourself

Locate the adder definition and its u_add instance. Explain why an edit to the definition affects every instance that uses it.

If it fails

If you opened a read-only leaf preview, return to Spec Editor and open the Design. If boundary ports cannot be edited after composition, use Circuit Designer’s boundary controls or return to the supplied start; do not edit archive files.

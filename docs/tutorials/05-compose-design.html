Compose a Design from Components

Create a containing Design with two reusable Component instances.

Before you startActionsCheck your resultTry it

Before you start

Spec Editor. The prepared start supplies the adder, register, and containing Component interface. It has no internal Design yet.

START HERE

temp/TEMP_tutorials/my-run/05-start.spec

Prepare or reset a lesson →

This lesson adds a supplied containing interface to the earlier results. Continue from your own Spec with the listed setup, or use this prepared checkpoint.

Actions

  1. Open 05-start.spec. If continuing your own Spec, first create a Component named Registered 16-bit adder, add the following six boundary ports while it is still a leaf, and paste the supplied explanation. The checkpoint avoids this repeated port entry.
    Port IDDirectionRangeDescription
    ain15:0First unsigned operand.
    bin15:0Second unsigned operand.
    clkinLeave blank (scalar)Rising-edge clock.
    resetinLeave blank (scalar)Synchronous active-high reset.
    enableinLeave blank (scalar)Capture the addition result.
    yout15:0Registered sum, modulo 65536.
    R1: On a rising clk edge with reset=1, y becomes zero, regardless of enable. R2: Otherwise, when enable=1, y captures (a+b) modulo 65536. R3: Otherwise y holds its value. Reset is synchronous and active high. The internal Design contains u_add and u_reg. There is one register stage. No valid signal or carry output is present.
  2. In Designs, select Add Design. Enter Registered adder implementation. Select Create design. In that Design’s Hardware settings, keep Entry Design selected.
  1. In the containing Component, expand Hardware settings. Set Internal Design to Registered adder implementation. Do not add a SystemVerilog section to the containing Component; its implementation will be the Design.
  2. In the Design, select Options → Add component instance…. Set Instance ID to u_add and Component to the existing 16-bit modulo adder definition. Select Add instance. Repeat with u_reg and Enabled 16-bit register.
  3. Inspect the instance table and circuit preview. Both instances refer to existing definitions. Open Options → Open in Circuit Designer on the Design. It must be an editable source-bound circuit, not a leaf preview.
SAVED-STATE CHECK

Check your result

The containing Component has six boundary ports and one internal Design. That Design has exactly u_add and u_reg, with no connections yet.

Try it yourself

Locate the adder definition and its u_add instance. Explain why an edit to the definition affects every instance that uses it.

If it fails

If you opened a read-only leaf preview, return to Spec Editor and open the Design. If boundary ports cannot be edited after composition, use Circuit Designer’s boundary controls or return to the supplied start; do not edit archive files.

THE DESIGNER’S STARTING POINT

From your first Spec
to a saved circuit.

Build a small registered adder. Learn the controls, make a change, and check what was saved.

9 core guides5–8 minutes eachAbout 62 minutes total
Start with your first Spec →Jump in with a prepared checkpoint

For designers who know basic digital hardware and are new to spec2hw. Start with the running environment supplied to you. No model key is needed for manual authoring; the Assistant lesson has a prepared fallback.

Use one example throughout: a 16-bit modulo adder, followed by an enabled register. Every guide has a fresh starting point and a visible result check.

What a result means

A draft is not a saved Spec. Architecture approval is not a saved result. Lint is not functional simulation. Each guide tells you which result to check.
